# 応募フォームの送信先セットアップ

応募フォームの流れ

```
ブラウザ → /api/entry（このサイト） → Apps Script Web アプリ
                                        ├ スプレッドシートに1行追記
                                        ├ 担当者へ完了メール
                                        └ Drive にJSONでバックアップ
```

送信先は環境変数で差し替えられます。コードを触らずに宛先やシートを変更できます。

---

## 1. スプレッドシートと Apps Script を用意する

1. 応募を管理したいスプレッドシートを開く（これまで使っているものでOK。新規なら名前は
   **「Amaden採用LP 応募管理」** を推奨）
2. 「拡張機能 → Apps Script」を開く
3. `docs/gas/entry.gs` の中身をすべて貼り付けて保存

## 2. 宛先と合言葉をスクリプト プロパティに登録する

Apps Script の「プロジェクトの設定 → スクリプト プロパティ」で2つ追加します。
※メールアドレスはコードに書かず、ここに入れてください。

| プロパティ | 値 |
| --- | --- |
| `RECIPIENTS` | 完了メールの宛先をカンマ区切りで（3件） |
| `TOKEN` | 任意の長い文字列（下の `ENTRY_WEBHOOK_TOKEN` と同じ値） |

`TOKEN` は、デプロイURLを知った第三者からの投稿を弾くための合言葉です。
パスワード生成ツールなどで32文字程度のランダム文字列を作ってください。

## 3. Web アプリとしてデプロイする

「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」

- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**全員**

初回は Gmail / Drive の権限承認を求められるので許可します。
発行された `https://script.google.com/macros/s/.../exec` という URL を控えます。

> 動作確認：その URL をブラウザで開いて `OK` と表示されればデプロイ成功です。

## 4. Vercel に環境変数を登録する

Vercel のプロジェクト設定 → Environment Variables（Production / Preview の両方）

| 変数名 | 値 |
| --- | --- |
| `ENTRY_WEBHOOK_URL` | 手順3で控えたデプロイ URL |
| `ENTRY_WEBHOOK_TOKEN` | 手順2の `TOKEN` と同じ文字列 |

登録後、再デプロイすると反映されます。

---

## バックアップについて

1件の応募につき、次の3か所に残ります。

1. スプレッドシートの「応募一覧」シート（通常の管理用）
2. Drive の「Amaden採用LP 応募バックアップ」フォルダに JSON ファイル1件
   （ファイル名：`20260401-093015_山田太郎.json`）
3. 担当者3名への通知メール本文（全項目を記載）

スプレッドシートを誤って編集・削除しても、2 または 3 から復元できます。

## コードを変更せずに変えられるもの

- 通知メールの宛先 → スクリプト プロパティ `RECIPIENTS`
- 送信先そのもの（別のフォーム基盤に乗り換える等）→ `ENTRY_WEBHOOK_URL`

## 名称まとめ

| 対象 | 名称 |
| --- | --- |
| スプレッドシート | Amaden採用LP 応募管理 |
| シート | 応募一覧 |
| Drive バックアップフォルダ | Amaden採用LP 応募バックアップ |
| 通知メール件名 | 【応募】山田太郎さん｜Amaden採用サイト |

シート名・フォルダ名・件名は `docs/gas/entry.gs` の冒頭で変更できます。

## うまく動かないとき

| 症状 | 確認すること |
| --- | --- |
| 「送信先が未設定です」と出る | Vercel に `ENTRY_WEBHOOK_URL` が入っているか、再デプロイしたか |
| 「送信に失敗しました」と出る | Apps Script の「実行数」ログにエラーが出ていないか |
| シートには入るがメールが来ない | スクリプト プロパティ `RECIPIENTS` が入っているか、迷惑メールフォルダ |
| ログに `unauthorized` | `TOKEN` と `ENTRY_WEBHOOK_TOKEN` の文字列が一致しているか |

送信が失敗した場合でも、応募内容は Vercel のファンクションログに残ります。

# Google Tag Manager

GTM ID `GTM-P6QHRW9C` を `src/app/layout.tsx` に埋め込み済みです。

- `<head>` の先頭にスニペット
- `<body>` 直下に noscript の iframe

応募完了時に `dataLayer` へ `entry_form_submit` イベントを送っているので、
GTM 側で「カスタムイベント＝`entry_form_submit`」のトリガーを作れば
応募完了をコンバージョンとして計測できます。
