## 解析して確定した座標系

| | ビューポート | 画像上の幅 | 倍率 | コンテンツ幅 |
| --- | --- | --- | --- | --- |
| PC | 1080px | 2160px（＋スクロールバー32px） | 2.0 | 968px（左右パディング56px）/ 750px（募集要項・FAQ・フォーム） |
| SP | 375px  | 562px（左右に余白6px/61px） | 1.4987 | 331px（左右パディング22px） |

- PC は `2160 / 2 = 1080`、スクロールバー幅が 16px ちょうどになることから DPR=2 と確定。
- SP は全面ブリード行のオレンジが x6–567 に収まることから実幅562px、`562 / 375 ≒ 1.4987` と確定。
- 実装の各セクション位置は上記換算値（画像px ÷ 倍率）をそのまま CSS px として使用しています。
