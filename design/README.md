# 参照デザイン（正解デザイン）

Google Drive の完成LPデザインを、実装時のピクセル比較用に配置しています。

| ファイル | 内容 | 元ファイル |
| --- | --- | --- |
| `pc_full.jpg` | PC版LP 全体（**要アップロード**） | `PC/amaden.jpg` |
| `pc_qa.jpg` | PC版 よくある質問 展開状態 | `PC/QA開いた時.jpg` |
| `sp_full.jpg` | SP版LP 全体（**要アップロード**） | `SP/amaden (1).jpg` |
| `sp_qa.jpg` | SP版 よくある質問 展開状態 | `SP/QA開いた時 (1).jpg` |

`pc_full.jpg` / `sp_full.jpg` は Drive のダウンロードホストが本セッションの
egress ポリシーで遮断されており、Drive 連携経由でも 1MB 超で転送が切れるため
取得できませんでした。このフォルダに同名でアップロードしてください。
